# Решение проблем с деплоем

## Проблема: Отображается только favicon и заголовок, остальное не загружается

### Причина
JS и CSS файлы не загружаются с сервера.

### Решение

#### 1. Проверьте, что все файлы загружены

Убедитесь, что на сервере загружены **ВСЕ** файлы из папки `dist/`:

```
dist/
├── index.html          ✅
├── .htaccess          ✅ (важно!)
├── favicon.ico        ✅
├── logo.png           ✅
├── placeholder.svg    ✅
├── robots.txt         ✅
└── assets/            ✅ (ВСЯ ПАПКА!)
    ├── index-*.js
    ├── vendor-*.js
    ├── router-*.js
    └── index-*.css
```

**Важно:** Папка `assets/` должна быть загружена полностью со всеми файлами внутри!

#### 2. Проверьте структуру на сервере

На сервере структура должна быть такой:
```
public_html/ (или www/)
├── index.html
├── .htaccess
├── favicon.ico
├── logo.png
├── placeholder.svg
├── robots.txt
└── assets/
    ├── index-*.js
    ├── vendor-*.js
    ├── router-*.js
    └── index-*.css
```

**НЕ должно быть:**
```
public_html/
└── dist/          ❌ НЕПРАВИЛЬНО!
    └── ...
```

#### 3. Проверьте права доступа

Установите правильные права:
```bash
# Файлы
chmod 644 *.html *.css *.js *.ico *.png *.svg *.txt

# Папки
chmod 755 assets/
```

#### 4. Проверьте в браузере

Откройте консоль разработчика (F12) и проверьте:
- Вкладка **Console** — есть ли ошибки?
- Вкладка **Network** — загружаются ли файлы из `/assets/`?

Если файлы не загружаются (404 ошибка):
- Проверьте, что папка `assets/` загружена на сервер
- Проверьте, что файлы находятся в правильной директории

#### 5. Проверьте .htaccess

Убедитесь, что файл `.htaccess` загружен и находится в корне сайта.

#### 6. Временное решение для проверки

Создайте тестовый файл `test.txt` в папке `assets/` и попробуйте открыть:
`https://ваш-домен.com/assets/test.txt`

Если файл не открывается — проблема в загрузке папки `assets/`.

### Быстрая проверка

Выполните на сервере (если есть SSH доступ):
```bash
cd /path/to/your/website
ls -la assets/
```

Должны быть видны файлы:
- `index-*.js`
- `vendor-*.js`
- `router-*.js`
- `index-*.css`

Если папка пустая или отсутствует — перезагрузите файлы.
