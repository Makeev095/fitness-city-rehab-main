# Инструкция по деплою Fitness City

## Подготовка к деплою

### 1. Установка зависимостей

```bash
npm install
```

### 2. Сборка production версии

```bash
npm run build
```

После выполнения команды будет создана папка `dist/` с готовыми файлами для загрузки на хостинг.

### 3. Проверка production сборки локально

```bash
npm run preview
```

Это запустит локальный сервер для проверки production версии перед загрузкой на хостинг.

## Загрузка на хостинг

### Вариант 1: Через FTP/SFTP

1. Подключитесь к вашему хостингу через FTP клиент (FileZilla, WinSCP и т.д.)
2. Перейдите в корневую директорию вашего домена (обычно `public_html/` или `www/`)
3. Загрузите **все содержимое** папки `dist/` на хостинг
4. Убедитесь, что файл `.htaccess` также загружен (важно для Apache серверов)

### Вариант 2: Через SSH

```bash
# Соберите проект
npm run build

# Загрузите содержимое dist/ на сервер
# Например, через scp:
scp -r dist/* user@your-server.com:/path/to/website/
```

### Вариант 3: Через панель управления хостингом

1. Соберите проект: `npm run build`
2. Создайте ZIP архив папки `dist/`
3. Загрузите через файловый менеджер панели управления
4. Распакуйте архив в корневую директорию сайта

## Важные файлы для загрузки

Убедитесь, что загружены:
- ✅ `index.html` (главный файл)
- ✅ `assets/` (папка со всеми JS, CSS и другими ресурсами)
- ✅ `.htaccess` (для Apache серверов - важно для работы роутинга)
- ✅ `favicon.ico` (иконка сайта)
- ✅ Все остальные файлы из папки `dist/`

## Настройка домена

### Если у вас Apache сервер

Файл `.htaccess` уже настроен и должен работать автоматически. Убедитесь, что:
- Модуль `mod_rewrite` включен на сервере
- Файл `.htaccess` загружен в корневую директорию сайта

### Если у вас Nginx

Создайте конфигурацию:

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/your/website;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # Кеширование статических файлов
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

### Если у вас другой сервер

Убедитесь, что все запросы перенаправляются на `index.html` (SPA routing).

## Проверка после деплоя

1. Откройте ваш сайт в браузере
2. Проверьте, что главная страница загружается
3. Проверьте навигацию (переходы между секциями)
4. Проверьте, что все изображения загружаются
5. Проверьте мобильную версию

## Обновление сайта

Когда нужно обновить сайт:

1. Внесите изменения в код
2. Соберите проект: `npm run build`
3. Загрузите новое содержимое папки `dist/` на хостинг (замените старые файлы)

## Редактирование контента

Основной контент находится в файле:
- `src/config/siteConfig.ts` - контакты, ссылки, тексты

После изменения контента:
1. Соберите проект: `npm run build`
2. Загрузите обновленные файлы на хостинг

## Поддержка

Если возникли проблемы:
1. Проверьте, что все файлы загружены
2. Проверьте права доступа к файлам (обычно 644 для файлов, 755 для папок)
3. Проверьте логи сервера
4. Убедитесь, что `.htaccess` работает (для Apache)
