  СПИСОК ФАЙЛОВ ДЛЯ ЗАГРУЗКИ НА TIMEWEB
═══════════════════════════════════════════════════════════════

Загрузите ВСЁ содержимое папки dist/ в корень вашего домена на Timeweb

СТРУКТУРА ФАЙЛОВ:
─────────────────

dist/
│
├── index.html              ← Главный файл (ОБЯЗАТЕЛЬНО!)
├── .htaccess               ← Конфигурация Apache (ОБЯЗАТЕЛЬНО!)
├── favicon.ico             ← Иконка сайта
├── logo.png                ← Логотип
├── placeholder.svg          ← Заглушка для изображений
├── robots.txt              ← Для поисковых систем
│
└── assets/                 ← Папка с JS и CSS (ОБЯЗАТЕЛЬНО!)
    ├── index-*.css         ← Стили сайта
    ├── index-*.js          ← Основной JavaScript
    ├── router-*.js         ← Роутинг
    └── vendor-*.js         ← Библиотеки (React и т.д.)

═══════════════════════════════════════════════════════════════
  ВАЖНО!
═══════════════════════════════════════════════════════════════

1. Загружайте ВСЁ содержимое папки dist/, а не саму папку
2. Файл .htaccess ОБЯЗАТЕЛЕН для работы страниц /documents и /privacy-policy
3. Папка assets/ должна быть загружена полностью со всеми файлами
4. Все файлы должны быть в корневой директории домена (public_html/ или www/)
