# 🚀 Быстрый старт для деплоя Fitness City

## Подготовка к деплою (один раз)

1. **Установите зависимости:**
   ```bash
   npm install
   ```

## Сборка и деплой

### Автоматический способ (рекомендуется):

```bash
./deploy.sh
```

Или вручную:

```bash
npm run build
```

После этого все готовые файлы будут в папке `dist/`

## Загрузка на хостинг

### Что загружать:
- **ВСЁ содержимое** папки `dist/` (включая подпапки)
- Особенно важно: файл `.htaccess` (для Apache серверов)

### Куда загружать:
- В корневую директорию вашего домена
- Обычно это: `public_html/` или `www/` или корень домена

## Редактирование контента

Основной файл для редактирования:
- `src/config/siteConfig.ts` - здесь все контакты, ссылки, тексты

После редактирования:
1. `npm run build` (или `./deploy.sh`)
2. Загрузите обновленные файлы из `dist/` на хостинг

## Проверка локально перед загрузкой

```bash
npm run preview
```

Откроет локальный сервер для проверки production версии.

## Важно!

- ✅ Убедитесь, что файл `.htaccess` загружен на сервер
- ✅ Загружайте ВСЁ содержимое папки `dist/`, а не саму папку
- ✅ После изменений всегда делайте новую сборку (`npm run build`)

## Проблемы?

Смотрите подробную инструкцию в файле `DEPLOY.md`
